# Timetric

> Timetric was a London-based data platform founded in 2008 for publishing, analysing, and performing calculations on large quantities of time-varying statistical data, later providing online market data, analysis, and advisory services to the insurance, construction, and infrastructure sectors. Timetric was acquired by GlobalData in March 2018; timetric.com now redirects to globaldata.com and the Timetric API no longer operates.

Timetric was backed by Anthemis and is profiled in the API Evangelist network as a historical (acquired/defunct) company. The Timetric Platform exposed an API with OAuth and API-token authentication for creating, reading, and updating time series; the only published client was a third-party Python library.
